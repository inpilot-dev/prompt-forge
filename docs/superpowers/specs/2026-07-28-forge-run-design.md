# forge-run 설계 (prompt-forge 실행 브릿지)

> 상태: 구현·검증 완료 (2026-07-28). 최초 설계(`docs/specs/2026-07-22`)의 진화 경로상 **v2**에 해당한다
> — v2의 다른 축인 E 로그 리뷰어와 병렬. 엔진 계보가 아니라 실행 브릿지 계보다.

## 왜 만드나

forge는 철칙상 **절대 실행 안 하고** 다듬은 프롬프트만 뱉는다(도구 무관 복붙용). 그래서 매번 사용자가 복붙해 실행해야 한다.
`forge-run`은 그 마지막 수고를 없앤다: 다듬은 프롬프트를 **곧바로 이 세션에서 실행**한다.

**forge와의 유일한 차이:** forge는 멈춘다(복붙용). forge-run은 안 멈추고 실행한다. 딱 그 한 지점.

## 아키텍처 (A안 — 얇은 브릿지·보여주고 실행)

- 원본 `prompt-forge`는 **불변**. 철칙 그대로.
- `forge-run`은 forge의 다듬기 절차를 재사용하되, 5단계(멈춤) 대신 **실행**으로 끝낸다.
- **patterns/ 심링크 공유** — forge와 같은 패턴 라이브러리를 참조(DRY). forge가 조사로 패턴을 늘리면 forge-run도 자동 최신. 로직 복제 없음.

```
raw 프롬프트
 → [1] forge 5단계로 다듬기 (patterns/ 공유, 조용히)
 → [2] 다듬은 프롬프트를 코드블록으로 출력 (투명성)
 → [3] 곧바로 이 세션에서 Claude가 실행
```

## 안전장치 (자동 실행이라 필수)

1. **빈칸/부족분이면 실행 금지 → 먼저 물음.** forge가 슬롯 부족으로 `[빈칸]`을 남기거나 역인터뷰 질문이 필요한 상태면,
   그대로 실행하지 않는다(반쯤 명세된 작업을 멋대로 수행 = 방지 대상). 부족분을 먼저 채우고(최대 3질문) 그다음 실행.
   **부족분 단위는 필수 슬롯(small 2·large 3)이며, 질문 후에도 슬롯이 안 채워지면 빈칸을 남기고 실행하지 않는다.**
   ("알아서 해"는 답으로 세지 않는다. 초기 `>3 → 빈칸` 분기는 슬롯 상한을 넘을 수 없어 삭제됨.)
2. **위험 작업은 평소 실행 안전규칙 그대로.** 다듬은 작업이 파괴적·외부발신(삭제·배포·이메일·push 등)이면
   forge-run이라고 건너뛰지 않는다 — 평소처럼 확인받고 진행. "자동 실행"이 "안전 무시"는 아니다.
3. **원본 forge 불변.** patterns/만 공유(심링크), forge SKILL.md는 건드리지 않는다.

## 에러 처리

- raw 프롬프트 없음 → "실행할 프롬프트를 붙여줘" 한 줄 요청.
- 실행 중 작업 실패 → 평소대로 실패를 그대로 보고(숨기지 않음).

## 스킬 계약

```
트리거: /forge-run <프롬프트>, "다듬어서 바로 실행해", "forge하고 돌려"
입력: raw 프롬프트
동작: 다듬기 → 다듬은 프롬프트 출력 → (빈칸 없으면) 실행
출력: ① 다듬은 프롬프트(코드블록) ② 실행 결과
      빈칸/부족 시: 실행 대신 최대 3질문
```

## 전역 배포

- 파일: `skills/forge-run/SKILL.md` + `patterns` 심링크(forge와 동일 대상).
- 전역화: `~/.claude/skills/forge-run` → repo의 `skills/forge-run` 심링크.
  `~/.claude/skills/`는 유저 레벨이라 **모든 세션·모든 repo**에서 뜬다(prompt-forge·prompt-rate-review와 동일 방식).

## 검증 (실행하는 스킬이라 행동 테스트)

1. **명세 충분** 프롬프트 → 다듬은 프롬프트를 보여주고 + 실행해 결과를 낸다.
2. **명세 부족** 프롬프트 → 실행하지 않고 **먼저 질문**한다(빈칸 실행 방지 확인).
3. **원본 prompt-forge diff 없음** 확인(forge SKILL.md 불변).

## v1 스코핑 (YAGNI)

| 넣음 (v1) | 안 함 |
|--|--|
| 다듬기(patterns 공유) → 보여주기 → 이 세션 실행 | 외부 LLM API 실행(다른 프로바이더) |
| 빈칸 실행 방지 + 부족분 최대 3질문 | 서브에이전트/다른 에이전트로 위임 실행 |
| 위험 작업 평소 안전규칙 준수 | rate-review 연동(실행 전 채점 게이트) |
| 전역 심링크 배포 | 실행 결과 로그 누적 |
