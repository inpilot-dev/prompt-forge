# prompt-forge 설계 스펙

> 2026-07-22 브레인스토밍 결과. 거지 프롬프트를 검증된 패턴(실밸개발자/알렉스 16패턴 등)으로
> 재조립해 주는 Claude Code 스킬 + 성장하는 패턴 라이브러리.

## 목적

- 아무렇게나 쓴 프롬프트를 **맥락에 맞는 GOOD 프롬프트**로 변환 (복붙용 출력, 실행 안 함 — 도구 독립)
- 패턴 라이브러리는 조사(C)로 계속 성장. 엔진은 불변, 재료만 늘어남
- 원 출처: `VideoOnly/AX-인재전쟁-해커톤-워크플로우/00_프롬프트-설계-BAD-vs-GOOD.md` (16패턴 × 8단계)

## 범위

- **v1 (이번 구현):** A 엔진(SKILL.md) + 기존 16패턴 이식 + 조사 루브릭
- **범위 밖:** C 조사 실행(스킬 완성 후 별도 세션), E 로그 리뷰어(v2), 플러그인화(v3), 풀스택 플러그인(별개 프로젝트)

## 패턴 파일 형식 (계약서)

모든 패턴은 이 블록의 반복:

```markdown
## 역인터뷰 (reverse-interview)
- **단계:** 킥오프
- **언제:** 맥락이 내 머리에만 있고 에이전트는 모를 때
- **Bad:** "아이디어 3개만 줘"
- **Good:** "필요한 정보는 네가 나를 인터뷰해서 수집해"
- **왜:** 에이전트가 스스로 필요한 컨텍스트를 정의하게 함
- **출처:** 실밸개발자 39분 §2-1        ← 한 줄만 (중복제거·충돌판정·재확인용)
```

단계 분류는 BAD-vs-GOOD의 0~8을 그대로 사용:
킥오프 / 컨텍스트주입 / 리서치위임 / PRD / 스코핑 / 솔루션깎기 / 검증기 / 구현위임 / 검증루프.

`_INDEX.md`는 `| 단계 | 패턴 | 파일 |` 역인덱스 한 장.

## 엔진 동작 (SKILL.md)

호출: `/prompt-forge <프롬프트>` 또는 "이 프롬프트 다듬어줘".

```
1. 크기 판단      small(단일 작업) / large(프로젝트급)
2. 맥락 검사      small: ①목표 ②완료판단 / large: ①목표 ②평가자 ③산출물 형태
                 → 부족하면 최대 3개 질문 (역인터뷰). 3개 초과 부족 시
                   빈칸 [ ] 있는 프롬프트를 출력하고 부족분 명시
3. 패턴 선택      _INDEX.md 읽기.
                 small → 문제정의+검증방법+범위제한 3~4개만
                 large → 해당 단계 풀세트
4. 변환 출력      변환 프롬프트(코드블록) + 적용 패턴 목록 한 줄
5. 끝            실행하지 않음
```

핵심 결정:
- **질문 최대 3개** — 취조 금지
- **적용 패턴 항상 명시** — 사용자 학습 루프 + 향후 E 리뷰어의 데이터
- **small에 8단계 풀세트 금지** — 과잉 방지가 1급 요구사항

## 조사 루브릭 (RUBRIC.md)

출처 입장자격 4항목 × 상/중/하 — 상 2개 이상만 입장:

1. 프롬프트 원문 공개? (팁 나열 X)
2. 원리 설명? ("왜 되는지")
3. 재현 가능한 워크플로우?
4. 실전 결과물 증거?

기준선: 실밸/알렉스 영상 = 4개 전부 상.

조사 우선순위: ① 알렉스 전체 채굴 → ② 해외 고수 5~10명 (넓게 100개 긁기 금지).
조사 1회 = 패턴 파일 1개 추가.

## 진화 경로 (자리만)

- v1.x: C 조사로 패턴 파일 추가 (엔진 무변경)
- v2: E 로그 리뷰어 — A 사용 로그 2주+ 쌓인 뒤. 같은 patterns/를 읽는 두 번째 스킬
- v3: 플러그인화 (선택)

## 테스트 (v1 완료 판정)

1. BAD-vs-GOOD의 Bad 예시 3개 투입 → 출력이 문서의 Good과 같은 패턴을 쓰는가
2. small 케이스("버그 고쳐줘") → 8단계 풀세트가 붙지 **않는가** (과잉 방지)

## 결정 기록

- 상호작용: 기본 즉시 변환, 맥락 부족 시 인터뷰 전환 (하이브리드)
- 적용 범위: 크기 자동 조절 (small/large)
- 라이브러리 구조: 사람별 파일 + 단계별 INDEX
- 설치: 전용 repo `~/dev/prompt-forge` (+ 스킬 연결)
- 출력: 복붙용 텍스트만, 실행 안 함 (Codex 등 타 도구 호환)
